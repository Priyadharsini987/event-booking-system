# Event Booking System

A web-based event booking application where users can register for events through a form and their responses are automatically stored in Google Sheets.

## Features
- Event registration form
- User input validation
- Automatic storage of responses in Google Sheets
- Simple and user-friendly interface

## Tech Stack
- React
- HTML
- CSS
- JavaScript
- Google Sheets Integration

## How It Works
1. User fills out the event booking form.
2. Form data is sent to the backend integration.
3. Responses are automatically stored in Google Sheets.
4. Event organizers can view all registrations in the sheet.
